# Stone Paper Scissors Game 🎮

A Python terminal-based game.

## Features
- Play vs Computer
- Play vs Friend
- Score tracking
- Multiple rounds
- Input validation

## How to Run
1-Enter the number of rounds you want to play.

2-Select a game mode: computer or friend.

3-Enter your choice: stone, paper, or scissor.

4-In friend mode, Player 1 and Player 2 enter their choices in turn.

5-View the round winner and updated scores.

6-At the end of the game, check the final result.

Note: Type exit when prompted for a choice to quit the game
